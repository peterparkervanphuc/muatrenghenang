# Security Policy

## Supported Versions

For this project, we currently only provide security updates for the latest release. Older versions are not actively maintained for security patches.

| Version | Supported          |
| ------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **DO NOT** open a public issue on GitHub. Exposing vulnerabilities publicly can put the project and its users at risk.

**How to report:**
Please report the vulnerability privately by sending an email to: **jojobibi1013.gs@gmail.com**

**What to expect:**
* I will acknowledge receipt of your vulnerability report within 48 hours.
* I will investigate the issue and work on a fix as quickly as possible.
* Please allow me time to release a patch before you publicly disclose the vulnerability.

Thank you for helping to keep this project safe!
